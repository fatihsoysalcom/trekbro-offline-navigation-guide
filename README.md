# TrekBro Offline Navigation Guide

This example demonstrates the core technical concept behind "TrekBro," an offline navigation system. It simulates setting a "camp" location and then, from a changing "current" location, calculates the distance and bearing needed to return to the camp. This process relies solely on mathematical formulas (Haversine for distance, bearing calculation for direction) and does not require internet connectivity, illustrating how one can find their way back even in remote areas.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run `python main.py`.
